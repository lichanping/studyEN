# 本周课表沿用时间覆盖排序 PRD

> 文档日期：2026-08-01

## 1. 背景

当前 `schedule.html` 的今日/明日区支持把某节课的时间临时调成具体时刻，例如把邸睿从“上午”调整为 `09:00`。

但本周课表仍存在旧行为：

- 排序仍沿用原始 `period/time`，没有复用今日区的有效时间排序。
- 文案仍显示 `上午/晚上`，没有显示覆盖后的具体时间。

这会导致同一节课在今日区已经按 `09:00` 置顶，但在本周课表里仍显示为 `上午`，也无法稳定排到最前。

## 2. 目标

- 本周课表与今日/明日区共享同一套“有效时间”排序口径。
- 若某节课存在当天时间覆盖，本周课表应显示覆盖后的具体时间，如 `09:00`。
- 周视图排序、文案与今日区保持一致，避免用户误判真实排课顺序。

## 3. 设计

### 3.1 排序口径统一

- 周视图每日条目渲染前，改为调用 `sortEntriesByTime(items, dayDate)`。
- 这样可直接复用现有规则：
  - 停排置底
  - 请假置底
  - 按 `getEffectiveClock(entry, dateValue)` 升序排列

### 3.2 时间文案统一

- 新增一个周视图可复用的时间显示函数。
- 规则：
  - 若当天存在覆盖时间，显示覆盖后的 `HH:mm`
  - 否则若条目本身有具体 `time`，显示该时间
  - 否则回退到 `period`

## 4. 非目标

- 不修改今日/明日区的现有交互布局。
- 不调整“上午/下午/晚上”默认时间映射规则。
- 不引入新的持久化字段。

## 5. 验收标准

- AC-01：某节课在今日区调整为 `09:00` 后，本周课表对应日期显示 `09:00`。
- AC-02：同一天存在多节课时，本周课表按调整后的有效时间升序排序。
- AC-03：没有具体时间覆盖的条目，仍保持原有 `period` 文案兼容展示。
