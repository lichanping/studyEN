# PRD：正课课堂反馈统计数据便捷录入

## 一句话方案

“课堂反馈”里的 5 个统计项都支持在原输入框中用 `+` 追加数字；离开输入框后，系统自动求和，并用合计替换原表达式。

例如输入 `10+20+15`，失焦后输入框自动变成 `45`；下次可继续追加 `+10`，再次失焦后变成 `55`。

## 覆盖范围

以下 5 项使用完全相同的追加和自动求和方式：

1. 复习单词
2. 复习遗忘
3. 学前检测
4. 新学单词
5. 遗忘

## 页面怎么操作

### 只有一个数字时

老师直接输入数字。失焦后数字保持不变：

```text
复习单词： [ 30 ]
```

### 输入多个数字时

老师在原输入框中用 `+` 连接多个数字：

```text
输入时：复习单词 [ 10+20+15 ]
失焦后：复习单词 [ 45 ]
```

- 系统在失焦时校验表达式并自动求和。
- 求和成功后，输入框只保留合计，不保留原始分项。
- 页面始终只有一个输入框，不增加高度，也不占用额外横向空间。

### 在合计上继续追加

自动汇总后，老师可以继续在合计后输入 `+数字`：

```text
当前值：[ 45 ]
追加时：[ 45+10 ]
失焦后：[ 55 ]
```

无需重新输入之前的分项，适合课堂中持续追加统计数字。

### 输入兼容

- 支持直接输入或粘贴 `10+20+15`。
- 支持半角 `+`、全角 `＋` 和数字两侧的空格。
- 输入框获得焦点时不自动改变内容，只在失焦时汇总。

## 复习遗忘自动填入新学单词

这个现有功能必须保留，并适配多个数字求和。

### 保留后的规则

1. 老师第一次输入有效的“复习遗忘”数据并离开整个“复习遗忘”区域时，系统计算它的合计。
2. 系统用该合计覆盖“新学单词”的当前内容。
3. 本次页面中只自动填入一次。
4. 自动填入成功后，老师再次修改“复习遗忘”，不再自动覆盖“新学单词”。
5. “复习遗忘”为空、合计为 `0` 或包含错误时不填入，也不消耗这一次自动填入机会；之后输入有效正整数并离开时仍应自动填入。
6. 自动汇总和首次同步在同一次失焦中完成：先把“复习遗忘”变成合计，再把合计同步到“新学单词”。

示例：

```text
输入时：复习遗忘 [ 2+3+1 ]    新学单词 [ 30 ]
首次有效失焦后：
	复习遗忘 [ 6 ]          新学单词 [ 6 ]
再次修改复习遗忘为 [ 8 ] 并失焦：
	复习遗忘 [ 8 ]          新学单词仍为 [ 6 ]
```

即使“新学单词”原本显示默认值 `30`，也沿用当前行为，在首次自动填入时替换为“复习遗忘”的合计。

## 数字规则

- 每一项只接受非负整数，例如 `0`、`3`、`25`。
- 不接受负数、小数和字母。
- `10++20`、`10+a+20` 等错误内容不自动汇总，保留原内容并提示老师修改。
- 存在错误内容时不能生成课堂反馈。
- 5 项在生成课堂反馈和保存统计时都只使用失焦后的合计值。

## 原有统计功能保持不变

- “复习单词”合计和“复习遗忘”合计继续计算复习正确率。
- “新学单词”合计和“遗忘”合计继续计算新学正确率。
- “学前检测”继续使用合计值生成反馈文案。
- “新学单词”合计继续与“新学单词（英文+中文）”中的实际单词数核对。
- 课堂反馈文案只显示合计，不显示各个数字。
- 不改变历史统计数据结构。
- 不改阅读课、体验课和抗遗忘页。

## 验收场景

| 模块 | 回归点 | 操作步骤 | 预期结果 |
|---|---|---|---|
| 五项统计 | 单个数字 | 分别在 5 项中输入一个数字 | 5 项都正确显示该数字和合计 |
| 五项统计 | 失焦汇总 | 分别输入 `10+20+15` 后失焦 | 5 项的输入框都自动变成 `45` |
| 五项统计 | 继续追加 | 汇总为 `45` 后追加 `+10` 并失焦 | 输入框自动变成 `55` |
| 五项统计 | 空间保持 | 输入较长表达式并失焦 | 汇总后只显示合计，不新增控件或撑开页面 |
| 旧输入习惯 | 加号表达式 | 输入或粘贴 `10+20+15` | 自动汇总为 `45` |
| 复习遗忘联动 | 单项自动填入 | 输入 `6` 后首次离开该区域 | 新学单词被替换为 `6` |
| 复习遗忘联动 | 多项自动填入 | 输入 `2+3+1` 后首次离开该区域 | 新学单词被替换为合计 `6` |
| 复习遗忘联动 | 只填入一次 | 首次填入后把复习遗忘改为 `8` 并再次离开 | 新学单词不再被覆盖 |
| 复习遗忘联动 | 无效值不占机会 | 先以 `0` 离开，再输入 `5` 后离开 | 第一次不填入，第二次填入 `5` |
| 输入校验 | 非法内容 | 输入 `10++20`、负数、小数或字母 | 明确提示错误且不能生成课堂反馈 |
| 统计兼容 | 使用合计 | 录入多项后生成课堂反馈 | 正确率、反馈文案和统计存储都使用合计值 |
