# PRD：抗遗忘页面直接发送复习通知

文档日期：2026-09-27
版本：v0.1（MVP）

## 1. 背景

老师目前需要离开抗遗忘页面，到排课总览页面的“抗遗忘通知”控件复制通知。增加页面内入口后，可直接使用当前学员、复习时间和平台生成通知，减少页面切换和手工核对。

## 2. 目标

在抗遗忘页面直接生成并复制当前学员的复习通知，通知中的腾讯会议号必须匹配当前平台的抗遗忘会议配置。

## 3. 范围

### In Scope

- 在抗遗忘页面复习时间控件旁增加“复习通知”按钮。
- 从当前学员、复习时间和当前平台生成通知。
- 复用 `APP_MEETING_CONFIG.getAntiForgettingTencentMeetingTagByPlatform(platformId)`，不硬编码会议号。
- 通过现有剪贴板和长文案提示能力复制、展示通知。

### Out of Scope

- 不调用外部消息平台直接发送消息；“发送”沿用排课页操作习惯，生成并复制文案。
- 不自动递增或修改复习时间。
- 不提交抗遗忘反馈，不写入复习记录或 BFD 额外计费账本。
- 不修改排课总览已有的通知行为。

## 4. 通知内容

通知标题使用 `【抗遗忘温馨提醒-HH:mm】` 格式，只显示页面选定的复习时间，不显示日期。正文包含当前学员、当前平台抗遗忘腾讯会议号，以及准时参加/无法参加时提前告知的提示。缺少学员或有效复习时间时不复制，提示用户补全信息。

会议号通过共享配置解析，当前配置为：李校来啦 `332-6955-7102`、百分缔 `684-1587-8369`、麦穗英语 `569-8084-0547`。

## 5. 验收标准

1. 抗遗忘页面显示“复习通知”按钮。
2. 有效学员和复习时间下点击按钮，复制并展示标题含 `HH:mm`、不含日期，且包含学员和会议号的文案。
3. 三个平台分别使用自己的抗遗忘会议号。
4. 学员或复习时间缺失时给出提示，不复制通知。
5. 点击不修改复习时间、不提交反馈、不改变额外计费勾选状态。
6. 排课总览原有抗遗忘通知及正课通知不受影响。
