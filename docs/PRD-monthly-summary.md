# PRD: 学员月末总结自动化 & 统计功能增强

## 概述

为学员自动生成月末总结报告，基于 localStorage 和 IndexedDB 中已有的课堂数据，填充模板中的量化指标，辅助教练快速生成个性化总结。兼容全部平台，按当前选中的学员进行统计。

同时增强现有"正课统计"和"抗遗忘统计"按钮，支持按月统计模式（原有按天模式保留）。

---

## 优先级

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 月末总结报告生成 | **P0** | 核心需求，自动生成完整报告 |
| 请假记录录入 | P1 | 辅助功能，支持月末总结自动填充请假数据 |
| 统计按钮按月模式 | P1 | 增强现有功能，支持按月统计 |

---

## 数据源分析

| 数据源 | 存储位置 | Key 格式 | 数据结构 |
|--------|---------|---------|---------|
| 课程统计 | localStorage | `${userName}_classStatistics` | `{ [date]: { newWord, reviewWordCount, duration, platform, type } }` |
| 抗遗忘反馈 | IndexedDB (FeedbackDB) | userName | `{ forgetWords: { [date]: words }, feedbackEntries: ["YYYY-MM-DD(周X): rate% \| total \| correct", ...] }` |
| 总课时 | localStorage | `${userName}_总课时` | 字符串数字 |
| **请假记录（新增）** | localStorage | `${userName}_leaves` | `[{ date: "YYYY-MM-DD", reason: "事假/病假" }, ...]` |

## 功能一：月末总结报告（P0）

### 模板各 Section 计算逻辑

#### 一、本月核心学习数据

##### ✅ 本月正课次数 & 课时汇总

**计算逻辑：**
```
遍历 classStatistics，筛选：
- type === "词汇课" 或 type === "阅读完型语法课"
- date 在本月范围内（YYYY-MM）
- 去重：同一天多次记录只算 1 次

正课次数 = 符合条件的去重日期数
正课总时长 = SUM(对应记录的 duration)，单位：小时
```

**报告文案：**
```
✅ 本月正课次数：X节，共X小时（全勤/仅X次请假，出勤超棒！）
```

##### ✅ 本月累计学单词

**计算逻辑：**
```
遍历 classStatistics，筛选：
- type === "词汇课" 或 type === "阅读完型语法课"
- date 在本月范围内

新词 = SUM(newWord)（词汇课 + 阅读课）
旧词巩固 = SUM(reviewWordCount)（所有课时类型的九宫格复习词）
累计学单词 = 新词 + 旧词巩固
```

**报告文案：**
```
✅ 本月累计学单词：X个（新词学习X个+旧词巩固X个）
```

##### ✅ 本月抗遗忘复盘

**计算逻辑：**
```
遍历 IndexedDB feedbackEntries，筛选：
- entry 日期在本月范围内
- 格式: "YYYY-MM-DD(周X): rate% | totalWordsReviewed | correctWordsCount"

抗遗忘复盘单词数 = SUM(totalWordsReviewed)
抗遗忘正确率 = SUM(correctWordsCount) / SUM(totalWordsReviewed) * 100%
```

**文案逻辑：**
- 抗遗忘正确率 > 80% → "正确率持续保持高位"
- 抗遗忘正确率 60%-80% → "正确率稳步控制👏"
- 抗遗忘正确率 < 60% → "继续加油，抗遗忘需要更多练习💪"

#### 二、本月表现点评

**全自动生成，无需手动编辑。** 根据以下 4 个核心指标分档输出话术：

| 指标 | 优秀 | 良好 | 待提升 |
|------|------|------|--------|
| 正课出勤 | >= 4 次/月 | 2-3 次/月 | < 2 次/月 |
| 学单词正确率 | >= 90% | 75%-89% | < 75% |
| 抗遗忘正确率 | >= 90% | 75%-89% | < 75% |
| 抗遗忘次数 | >= 4 次/月 | 2-3 次/月 | < 2 次/月 |

##### 👍 闪光点（自动挑选 2-3 条）

| 指标达标 | 自动生成话术 |
|---------|------------|
| 学单词正确率 >= 90% | ▫️ 记词效率高，接受度强，新单词掌握又快又扎实💪 |
| 抗遗忘正确率 >= 90% | ▫️ 抗遗忘意识足，主动配合复盘，旧词巩固到位✅ |
| 正课出勤 >= 4 次 | ▫️ 课堂专注认真，积极互动，单词疑问及时问，态度超赞👍 |
| 抗遗忘正确率逐周上升 | ▫️ 易混词/易错词能及时订正，二次出错率低，进步超明显✨ |
| 总课时 >= 8 小时 | ️ 自主学习性强，课后能主动打卡，坚持超给力🌟 |

**挑选规则：** 按指标从高到低排序，最多输出 3 条。若全部指标都优秀，输出前 3 条。

##### 📌 小提升点（自动挑选 1-2 条）

| 指标未达标 | 自动生成话术 |
|-----------|------------|
| 学单词正确率 < 90% | ▫️ 部分单词需多结合语境记忆，避免混淆📝 |
| 抗遗忘次数 < 4 次 | ️ 抗遗忘可增加碎片化复习，记得更牢🔄 |
| 正课出勤 < 4 次 | ▫️ 遇到难词别畏难，多主动提问，突破更快哦～ |

**挑选规则：** 按指标从低到高排序（最弱的优先），最多输出 2 条。若全部指标都优秀，输出"本月表现很棒，继续保持！"。

#### 三、下月小目标

**固定模板 + 数据驱动微调：**

| 目标 | 数据驱动逻辑 |
|------|-------------|
| 持续积累单词 | 固定文案 |
| 针对性攻克薄弱点 | 若本月抗遗忘正确率 < 70%，强调"减少同类错误" |
| 保持好状态 | 若本月全勤，强调"继续保持"；若有请假，强调"出勤稳定" |

#### 四、教练暖心寄语

**固定模板 + 个性化变量：**

```
本月[学生名]的坚持和进步都看在眼里！
[数据亮点：如"累计学XX词，抗遗忘XX次"]
保持这份劲头，坚持抗遗忘、稳积累，下月一定能更上一层楼，越来越优秀！
```

## 功能三：统计按钮按月模式（P1）

### 现状

现有"正课统计"和"抗遗忘统计"按钮使用 `daysRangeInput`（天数输入框）按天统计：
- 输入 `1` 天 → 统计最近 1 天数据
- 输入 `7` 天 → 统计最近 7 天数据

### 增强：支持按月统计

在" 数据统计"区域新增月份选择器，支持两种模式切换：

```
┌─────────────────────────────────────────────────────┐
│  天 [1]  [抗遗忘统计] [正课统计] [工资统计]            │
│  月 [2026-08▼]  [抗遗忘统计] [正课统计]               │
└─────────────────────────────────────────────────────┘
```

**交互逻辑：**
- 默认显示"天"模式（现有行为不变）
- 点击"月"模式 → 显示月份选择器（默认本月）
- 点击"抗遗忘统计"/"正课统计" → 根据当前模式（天/月）执行统计

**按月统计逻辑：**
- 正课统计：筛选 `classStatistics` 中 date 在选中月份的数据
- 抗遗忘统计：筛选 `feedbackEntries` 中日期在选中月份的数据

## 验收标准

### P0 — 月末总结报告
1. 选择月份后，正课次数+小时数、学单词数、抗遗忘复盘数准确
2. 闪光点/小提升点全自动生成，无需手动编辑
3. 生成的报告为纯文本格式，复制到剪贴板并支持导出 .txt
4. 兼容全部平台，按当前选中学员统计

### P1 — 请假记录录入
6. 课程信息区有"记录请假"按钮，点击弹出表单
7. 表单自动填充当前学员和今天日期
8. 选择请假类型（事假/病假）后确认，数据存入 localStorage
9. 可查看/删除已有请假记录

### P1 — 统计按钮按月模式
10. 数据统计区支持天/月模式切换
11. 按月模式选择月份后，正课统计和抗遗忘统计输出该月数据
12. 原有按天模式功能不受影响

### 集成验收
13. 月末总结弹窗中请假次数自动从请假记录读取，可手动覆盖
14. 手动清空请假输入框视为 0 次请假

## 本次更新 Summary

### 新增内容
1. **优先级定义**：明确月末总结报告为 P0，请假录入和统计增强为 P1
2. **统计按钮按月模式**：正课统计和抗遗忘统计支持按月统计，原有按天模式保留

### 改动范围

- `monthly-summary.js`（新增）：月末总结报告生成逻辑

### 数据流
```
课堂反馈 → classStatistics (localStorage)
                    ↓
              月末总结报告 ← 请假记录 (localStorage)

                    ↓
              月末总结报告
```
