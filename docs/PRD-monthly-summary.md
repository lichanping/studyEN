# PRD: 学员月末总结自动化与统计增强

## 概述

在正式课页面新增一套完整的月末总结工具，基于现有 localStorage 和 IndexedDB 数据，自动生成学员月末总结；同时补齐请假记录管理，以及正课统计、抗遗忘统计的按月模式。

本次实现范围包含：

1. P0 月末总结报告生成
2. P1 请假记录录入、查看、删除
3. P1 数据统计区的按天/按月模式切换
4. P2 正课历史数据扩展字段预埋

## 需求澄清

### 现有真实数据源

| 数据项 | 当前来源 | 当前状态 |
|---|---|---|
| 正课次数、课时、新词数、复习词数 | `${userName}_classStatistics` | 已存在，可直接复用 |
| 抗遗忘复盘词数、正确率 | `FeedbackDB.feedbackData.feedbackEntries` | 已存在；本次需将“新版反馈”也归并到同一记录来源 |
| 请假记录 | `${userName}_leaves` | 本次新增 |

### 抗遗忘反馈记录归并约束

1. 月末总结统计抗遗忘复盘时，统一只读取 `FeedbackDB.feedbackData[userName].feedbackEntries`。
2. 点击 `抗遗忘课堂反馈` 与点击 `新版反馈` 后，都需要写入同一种复习记录格式，便于月末总结统一汇总。
3. 复习记录沿用现有格式：`YYYY-MM-DD(周X): rate% | totalWordsReviewed | correctWordsCount`。
4. 同一学员同一天若重复写入复习记录，继续沿用现有“按日期覆盖”的行为，后一次写入覆盖前一次写入；本次不新增“同日多条并存”的存储结构。
5. `forgetWords` 明细文本仍属于课堂反馈附加信息，不作为月末总结统计的唯一数据源。

## 优先级

| 功能 | 优先级 | 说明 |
|---|---|---|
| 月末总结报告生成 | P0 | 核心需求 |
| 请假记录录入与管理 | P1 | 支撑月末总结自动填充 |
| 按月统计模式 | P1 | 增强现有统计能力 |
| 正课 forget new words 历史字段预埋 | P2 | 为后续统计/分析扩展准备数据 |

## 功能一：月末总结报告（P0）

### 入口

在 [index.html](index.html) 的“数据统计”区域新增“月末总结”按钮。

### 模态框字段

1. 学员：自动读取当前选中学员
2. 月份：`type="month"`，默认本月
3. 本月请假次数：自动读取，可手动覆盖；手动清空视为 `0`
4. 数据预览：展示正课次数、课时、累计学词、正课遗忘词/新词掌握率、抗遗忘复盘
5. 自动点评：展示闪光点、小提升点
6. 生成报告：生成纯文本，并自动复制、下载 `.txt`

### 统计逻辑

#### 本月正课次数与课时

1. 数据源：`${userName}_classStatistics`
2. 统计 `type === "词汇课"`、`type === "阅读完型语法课"`、`type === "体验课"`
3. 仅统计所选月份内的数据
4. 同一天多条记录只算 1 次正课
5. 课时为所选月份内所有命中记录的 `duration` 之和

#### 本月累计学单词

1. 新词：`SUM(newWord)`
2. 旧词巩固：`SUM(reviewWordCount)`
3. 统计范围与正课次数一致，包含体验课、词汇课、阅读完型语法课
4. 累计学单词：新词 + 旧词巩固

#### 本月正课遗忘词与掌握率

1. 数据源：`${userName}_classStatistics[*].forgetNewWords`
2. 仅统计所选月份内、且 `type === "词汇课"`、`type === "阅读完型语法课"`、`type === "体验课"` 的记录
3. 正课遗忘词总数：`SUM(forgetNewWords)`
4. 正课新词掌握率按月汇总计算，不直接看单条记录：
  `SUM(newWord - forgetNewWords) / SUM(newWord) * 100`
5. 若当月 `SUM(newWord) === 0`，则正课新词掌握率记为“无数据”，不展示为 `0%`
6. 历史旧数据缺少 `forgetNewWords` 时按 `0` 兼容读取；该场景可接受按“0遗忘、100%掌握”口径参与月度汇总

#### 本月抗遗忘复盘

1. 数据源：`FeedbackDB.feedbackData[userName].feedbackEntries`
2. 该数据源需同时包含点击 `抗遗忘课堂反馈` 与点击 `新版反馈` 后写入的复习记录
3. 两个按钮写入的记录格式保持一致：`YYYY-MM-DD(周X): rate% | totalWordsReviewed | correctWordsCount`
4. `totalWordsReviewed` 为当前页“复习词数输入框合计 + 重点语言点非空行数 + 语言闯关非空行数”
5. `correctWordsCount` 统一按 `totalWordsReviewed - forgetCount` 计算
6. `forgetCount` 取值规则分按钮来源：
  - 点击 `抗遗忘课堂反馈`：继续按现有逻辑，从“遗忘词（英文+中文）”文本框中统计英文单词数
  - 点击 `新版反馈`：不再读取“遗忘词（英文+中文）”文本框做统计，直接读取“遗忘：”输入框里的数字
7. 复盘词数：`SUM(totalWordsReviewed)`
8. 月度正确率不直接取单条记录中的 `rate%`，而是按所选月份全部命中记录先汇总：
  `SUM(correctWordsCount) / SUM(totalWordsReviewed) * 100`
9. 遗忘词数可按 `SUM(totalWordsReviewed) - SUM(correctWordsCount)` 回算，用于文案生成

#### 新版反馈文案

1. 点击 `新版反馈` 时，生成的反馈文案中需要展示“复习 X 词，遗忘 Y 词”。
2. 其中 `Y` 直接读取当前页“遗忘：”输入框中的数字，不从“遗忘词（英文+中文）”文本框重新计数。
3. 若用户选择“允许为空”跳过统计，则仍可不展示“复习 X 词，遗忘 Y 词”这一统计句。
#### 抗遗忘反馈按钮写库异同

1. 共同点
  - 都写入 `FeedbackDB.feedbackData[userName].feedbackEntries`
  - 都使用同一条统计记录格式：`YYYY-MM-DD(周X): rate% | totalWordsReviewed | correctWordsCount`
  - 都可被月末总结直接纳入抗遗忘复盘统计
  - 同一学员同一天重复写入时，都按日期覆盖旧记录
2. 差异点
  - `抗遗忘课堂反馈` 会继续依赖“遗忘词（英文+中文）”文本框统计 `forgetCount`
  - `新版反馈` 改为直接读取“遗忘：”输入框数字作为 `forgetCount`，不依赖遗忘词列表文本统计
  - `抗遗忘课堂反馈` 继续承载遗忘词明细、发音词明细等课堂反馈文案
  - `新版反馈` 本需求的核心是补齐月末总结所需的复习统计 record；不要求新增新的月末总结专用存储结构

#### 抗遗忘趋势

1. P0 采用轻量实现，不做复杂算法
2. 以周为粒度统计月内抗遗忘正确率
3. 若至少有两周有效数据，且最后一周高于第一周，则判定为 `rising`
4. 其余情况判定为 `stable`

### 自动点评规则

#### 闪光点

最多输出 3 条。

1. 抗遗忘正确率 `>= 90%`：`▫️ 抗遗忘意识足，主动配合复盘，旧词巩固到位✅`
2. 正课出勤 `>= 4`：`▫️ 课堂专注认真，积极互动，单词疑问及时问，态度超赞👍`
3. 抗遗忘趋势为 `rising`：`▫️ 易混词/易错词能及时订正，二次出错率低，进步超明显✨`
4. 总课时 `>= 8`：`▫️ 自主学习性强，课后能主动打卡，坚持超给力🌟`
5. 正课新词掌握率 `>= 90%`：`▫️ 本月新学内容掌握得比较扎实，课堂吸收效率不错👏`

#### 小提升点

最多输出 2 条。

1. 抗遗忘次数 `< 15`：`▫️ 抗遗忘复盘次数还可以再加一些，尽量把复习频率提上来，记得会更牢🔄`
2. 正课出勤 `< 4`：`▫️ 本月正课次数偏少，下月可适当多安排一些课程，保持学习节奏更稳📚`
3. 正课新词掌握率 `< 90%`：`▫️ 本月新学内容里还有一些词需要反复回看，建议课后把易忘词再多巩固几遍📝`
4. 若当月正课次数、总课时、累计学词均为 `0`，优先输出中性提示，不使用“全勤，出勤超棒”这类表扬话术
5. 零数据场景建议文案：`本月暂未安排正课，当前以节奏恢复和学习计划衔接为主。`
6. 未满足闪光点条件的指标，可优先转化为下月小目标或小提升点
7. 若全部维度优秀或可用维度全部达标，输出：`本月表现很棒，继续保持！`
8. 若当月正课次数、累计学词、抗遗忘复盘次数均为 `0`，则本段不输出基于学习表现的正向或负向判断，改用暖心寄语式鼓励话术
9. `0正课 + 0复习` 场景建议文案：`这个月我们先稍作调整，期待下个月一起把学习节奏慢慢找回来，继续稳稳往前走。`
10. `0正课 + 0复习` 场景下，不得出现“本月正课次数偏少”这类带比较意味的评价文案。

### 下月小目标生成

1. 下月小目标应优先承接本月未满足的闪光点指标
2. 目标文案需具体、可执行，不写空泛鼓励语
3. 示例文案：
  - 正课出勤 `< 4`：`下月适当增加正课安排，尽量保持每周稳定上课频率。`
  - 抗遗忘次数 `< 15`：`下月增加抗遗忘复盘次数，尽量形成更稳定的复习节奏。`
  - 抗遗忘正确率 `< 90%`：`下月继续针对易错词反复巩固，争取把抗遗忘正确率再往上提。`
  - 正课新词掌握率 `< 90%`：`下月继续加强新词课后回顾，尽量把课堂中容易遗忘的词及时滚动复习。`
  - 抗遗忘趋势非 `rising`：`下月继续优化复习状态，争取让后半月的抗遗忘表现更稳定向上。`
4. 若当月正课核心数据为 `0`，下月目标优先写“恢复稳定上课节奏”而不是沿用高完成度表扬口吻

### 输出格式

1. 标题格式：`${userName}学员8🈷️月末总结`
2. 若学员姓名为 3 个字，月末总结报告正文中的学员称呼去掉姓氏，仅保留后 2 个字；非 3 个字姓名保持原样
3. 下载的 txt 文件名仍使用学员完整姓名
4. 报告分四段：核心学习数据、表现点评、下月目标、暖心寄语
5. 自动复制到剪贴板
6. 自动下载 `${userName}_${yearMonth}_月末总结.txt`
7. 当某项核心统计为 `0` 或“无数据”时，文案应改为中性描述，不直接输出容易误导的正向结论
8. 示例：当正课次数、总课时、累计学词都为 `0` 时，第一段建议写为：`本月暂未安排正课，累计学词与课堂数据暂无可统计内容。`
9. 若本月正课为 `0`，但存在抗遗忘复盘记录，建议文案写为：`本月暂未安排正课，但复习节奏仍在持续保持。`
10. 若本月正课与抗遗忘复盘都为 `0`，建议整份总结统一使用暖心寄语式鼓励文案，例如：`这个月我们先稍作调整，期待下个月一起把学习节奏慢慢找回来，继续稳稳往前走。`
11. txt 报告正文第一段中，正课学习数据需与抗遗忘复盘保持同类格式，合并为单行展示：先写“本月累计学单词”，再补充“累计遗忘 X 词，综合正确率 Y%”。
12. 预览区也需按相同口径展示正课学习汇总：`累计学单词：...（...），累计遗忘 X 词，综合正确率 Y%`，且抗遗忘复盘行需同时展示“累计遗忘 X 词”和“综合正确率 Y%”。
13. 当本月正课与抗遗忘复盘都为 `0` 时，txt 总结需避免重复输出相同暖心文案；暖心寄语保留在“教练暖心寄语”段落即可，其它段落改为更简洁的事实描述。

## 功能二：请假记录管理（P1）

### 入口

在“课程信息”区域新增两个按钮：

1. `记录请假`
2. `查看请假记录`

### 数据结构

`localStorage` key: `${userName}_leaves`

value:

```json
[
  {
    "date": "2026-08-05"
  }
]
```

### 行为要求

1. 记录请假弹窗自动带出当前学员和当天日期
2. 只记录请假次数，不区分事假/病假等原因
3. 支持写入、列表查看、删除单条记录
4. 月末总结打开时自动汇总所选月份请假次数
5. 手动输入请假次数可覆盖自动值；清空输入框视为 `0`

## 功能三：统计按钮按月模式（P1）

### UI

在“数据统计”区域新增：

1. `按天` 单选
2. `天数输入框`
3. `按月` 单选
4. `月份选择器`

默认保持 `按天` 模式，与旧行为兼容。

### 交互逻辑

1. 选择 `按天`：正课统计、抗遗忘统计继续按最近 N 天输出
2. 选择 `按月`：正课统计、抗遗忘统计按所选月份输出
3. 原有工资统计保持现状，不切入按月逻辑

## 功能四：正课 forget new words 历史字段预埋（P2）

### 目标

在不改变本次 P0/P1 统计口径的前提下，为后续功能扩展预先沉淀正课历史数据。

### 范围

1. 每次提交 `体验课`、`词汇课`、`阅读完型语法课` 反馈时，`classStatistics` 除现有字段外，新增保存“新学后遗忘词数”。
2. 该字段用于表示：本次新学内容中，学后检测仍遗忘了多少词。
3. 本次仅要求数据写入 localStorage，不要求在月末总结、正课统计、抗遗忘统计中展示或计算。

### 数据约束

1. `forgetNewWords` 必须写入现有 `${userName}_classStatistics` 的单条记录 value 中。
2. 只能在原有记录基础上新增字段，不能调整 `classStatistics` 的顶层组织方式、key 规则或既有字段语义。
3. 具体存储形态以当前代码里的 `storeClassStatistics` 及其调用链为准，实现时按真实代码结构落盘，不在本 PRD 中写死。

### 行为要求

1. 体验课使用现有 `forgetWord` 输入值作为 `forgetNewWords` 持久化。
2. 词汇课/阅读完型语法课使用现有课堂反馈里的“新学遗忘词数”作为 `forgetNewWords` 持久化。
3. 历史旧数据没有该字段时，读取逻辑必须兼容，不能影响现有功能。
4. 本次版本不对该字段做任何统计展示，只做存储准备。

## 验收标准

### P0

1. 选择月份后，正课次数、课时、学词数、抗遗忘复盘词数准确，且正课统计需包含体验课
2. 闪光点、小提升点自动生成，无需手工编辑
3. 报告为纯文本，且自动复制、自动下载 `.txt`
4. 仅统计抗遗忘复习的正确率/遗忘情况，不要求正课月度正确率
5. 抗遗忘正确率需按月内全部命中记录汇总后统一计算，不直接使用单条 `rate%`
6. 点击 `新版反馈` 后也会写入 `FeedbackDB.feedbackData[userName].feedbackEntries`，且月末总结能统计到该条复习记录
7. 点击 `新版反馈` 时，复习记录里的遗忘词数直接取“遗忘：”输入框数字，不依赖遗忘词列表文本框
8. 同一学员同一天分别点击两个反馈按钮时，月末总结最终读取该日期最后一次写入的复习记录
9. 当正课次数、总课时、累计学词都为 `0` 时，月末总结不得输出“全勤，出勤超棒”这类误导性正向文案
10. 月末总结需额外统计正课遗忘词总数与正课新词掌握率，且 `>= 90%` / `< 90%` 的阈值边界与抗遗忘正确率口径保持一致
11. 当正课次数、累计学词、抗遗忘复盘次数均为 `0` 时，整份月末总结统一输出暖心寄语式鼓励文案，不输出任何表现评价型结论
12. `0正课 + 0复习` 场景下，小提升点不得出现“本月正课次数偏少”之类比较型文案。
13. 点击 `新版反馈` 后，生成的反馈文案中需展示“复习 X 词，遗忘 Y 词”，其中 `Y` 取“遗忘：”输入框数字。
14. 月末总结预览区与 txt 报告正文都需展示正课学习汇总中的“累计遗忘词”和“综合正确率”，计算口径与正课新词学习总数保持一致。
15. 抗遗忘正确率必须按月内全部命中记录汇总后统一计算，并保持现有全局整数百分比展示口径，使用四舍五入。例如存在 `10/10`、`200/200`、`9/10` 三条记录时，平均正确率按 `219/220` 汇总后展示为 `100%`。

### P1 请假记录

1. 可以新增请假记录
2. 可以查看并删除请假记录
3. 月末总结自动读取请假次数
4. 手动清空请假输入视为 `0`
5. 请假记录不区分请假原因

### P1 按月统计

1. 正课统计支持按月
2. 抗遗忘统计支持按月
3. 原有按天模式不回归

### P2 历史字段预埋

1. 新提交的体验课、词汇课、阅读完型语法课记录会额外保存 `forgetNewWords`
2. 历史没有该字段的数据仍可正常读取和统计
3. 本次版本不消费该字段做统计输出
