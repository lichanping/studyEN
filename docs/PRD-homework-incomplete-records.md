## 背景与目标

教练需要登记哪一天正课对应的课后复习没有提交，便于持续督促、查询和统计。主要使用场景是 BFD 杨开迪，但登记、查看、删除和统计适用于所有平台、所有学员。

是否登记、是否删除由用户控制，不推断学生实际是否做过作业，不记录对学生或家长的评价。

## 范围

### 已确认需求

1. 在正式课首页“查看请假记录”后新增精简按钮：“记录未交作业”“查看未交记录”。
2. 在“数据统计”区域的“抗遗忘统计”后紧接新增“未交作业统计”按钮。
3. 登记、查看、删除、独立统计、月末总结披露均为通用功能，不硬编码杨开迪。
4. 用户只需输入未提交复习对应的正课日期，同一平台、同一学生、同一天允许一条记录。
5. 与请假记录一样支持直接删除，不增加补交状态、作废流程或历史保留机制。
6. 月末总结标题下第一节披露所选月份的登记次数和对应正课日期，原 section 编号顺延；没有记录时原报告不变。
7. 专项提醒文案的调整仍只对 BFD 杨开迪生效，其他平台和学生的课后复习要求不变。
8. 按已确认方案实现并完成本地及 Preview 验收，不自动合并 PR。

### 实现口径

- 第一版使用本机 localStorage，与现有请假记录管理的部署方式保持一致。
- 录入日期为正课日期，不是登记日期、作业截止日期或打卡日期。
- 同一天重复保存仍只有一条记录，不重复计数。
- 删除后从列表及重新生成的统计、月末总结中移除，由用户控制删除。
- 不增加作业摘要、未完成项、备注和处理状态等字段。
- 独立统计复用现有按天/按月选择，按同一日期和去重口径取数；具体输出方式见下文。

### 不在本期范围

- 自动读取微信群、判断学生是否做过作业、自动发送催交消息。
- 自动根据词汇遗忘率、复习次数或没有课堂数据生成未完成记录。
- 云端同步、多人协作、身份认证、防篡改审计或法律证据认证。
- 补交状态、作废、删除审计、历史保留、作业明细和备注管理。
- 作业图片、语音附件上传及保管。
- 费用、免费复学、课程服务范围调整。
- 修改原请假存储、课时、工资、排课或其他统计口径。
- 新增课后复习要求 TXT 下载功能。

## 文案调整

本轮要求：精简开迪专属文案，抓住作业与提交重点；除抄写外，增加英翻中、中翻英各默写一遍。不涉及费用和服务范围。

保留每词抄写三遍、朗读两遍、遗忘词次日复习、动态截止时间及未交登记说明；提交材料明确包含抄写、默写照片和朗读语音。

本轮已按最终确认文案实施：先更新现有专项全文测试并确认失败，再替换业务文案并验证通过。点击“课后复习方式”仍只输出提醒，不创建记录；登记由教练另行操作。

### 开迪课后复习方式精简文案（已确认）

下方“【动态截止时间】”为占位说明；实际点击时沿用现有规则生成“今晚/明天 HH:MM 前”，不固定为某个日期或时刻。

```text
开迪妈妈您好，今日作业如下：

2. 默写：英翻中、中翻英各默写一遍，再对照订正。
3. 朗读：全部单词朗读两遍。
4. 遗忘或写错的词记入生词本，次日复习自测。

特殊情况提前说明；未交作业按正课日期登记，月末反馈。
```

## 登记功能

### 入口与上下文

按钮顺序：记录请假 → 查看请假记录 → 记录未交作业 → 查看未交记录。

未选择学生时提示“请先选择学员”，不打开可保存的表单。弹窗显示当前平台和完整学生姓名，不在弹窗中切换学生。保存前核对首页选择仍与打开弹窗时一致，避免把记录写给另一位学生或平台。

### 字段

| 字段 | 要求 | 说明 |
| --- | --- | --- |
| 平台、学生 | 自动带出、只读 | 按当前页面选择隔离；姓名使用现有别名归一规则 |
| 正课日期 | 唯一可输入字段，必填，默认当天 | 用户输入未交复习对应的正课日期；允许补录历史日期，不允许未来日期 |

是否登记由用户判断，不自动判断未提交或逾期。只按日期区分对应正课复习，不要求该日期一定存在本机课堂统计，也不区分同一天多节正课。

### 保存与防误操作

1. 校验通过才写入；重复点击不产生重复记录。
2. 同平台、同学生、同一正课日期重复保存仍只保留一条，与请假记录一致。
3. 写入失败时保留输入并明确提示，不显示“已记录”。
4. 关闭或取消不保存；其他平台的同名学生不受影响。

## 查看与删除

查看当前平台、当前学生的全部记录，按正课日期排序。每条展示“YYYY-MM-DD 正课”及删除按钮，不逐行重复未交说明。

点击删除直接移除该条并刷新列表，与请假记录一致；不要求作废原因，不保留已删除记录，不增加补交或状态切换。更正日期使用删除后重新登记。

没有记录时显示“暂无未交作业记录”，不能据此宣称所有作业都完成。

## 未交作业统计

### 入口与统计范围

数据统计区按钮顺序：抗遗忘统计 → 未交作业统计 → 正课统计 → 工资统计。

新按钮为只读统计，不执行登记或删除。复用该区域现有控件：

- 按天：统计最近 N 天，包含今天，按正课日期命中该范围的记录计算。
- 按月：统计月份选择器选中的自然月，按正课日期所在月份计算。
- 只读取当前平台、当前学生，未选择学生时提示“请先选择学员”。

同一天一条对应一次未提交，总次数等于范围内去重后的正课日期数。删除后重新统计，次数和日期同步减少，不新增另一套记录存储。

### 输出与示例

沿用统计按钮的纯文本报告方式：自动复制、下载 TXT，并提示结果；三种输出使用同一份文本，统计不修改记录。

独立统计和月末总结面向家长的输出不得显示平台名称、平台 ID 或存在多个平台的提示，包括分享正文、复制内容、TXT 内容及文件名。平台仅用于内部存储隔离和筛选；教练登记/查看界面的内部上下文保持不变。

明细仅列正课日期，未交作业说明在汇总行统一呈现，不逐行重复。

```text
【未交作业统计】
学员：杨开迪
统计范围：2026-10-01 至 2026-10-03
未提交课后复习作业共 2 次，对应正课日期：
1. 2026-10-01
2. 2026-10-02
以上根据当前保留的登记记录汇总。
```

范围内没有记录时，仍输出“未提交课后复习作业共 0 次（所选范围暂无登记记录）”，不把零记录表述为“所有作业已完成”。

## 月末总结披露

### 取数口径

1. 按当前平台、当前学生、所选月份筛选；月份按正课日期归属，不按实际登记日期。
2. 未提交总次数为当月保留的去重记录条数，一条对应一天正课的课后复习。
3. 明细必须列出对应正课日期，不能只给总数，不区分待补交、已补交状态。
4. 删除后的记录不计入重新生成的报告，不自动改写之前已下载的 TXT。
5. 不计算完成率，也不推断未登记日期都已提交。
6. 没有记录时不增加新段落，不改原报告的标题和各段内容。
7. 独立统计选择相同月份时，其总次数和正课日期必须与月末披露一致。
8. 当月存在未交记录时，只去掉“课后能主动打卡”的自动表扬，不改其他点评；没有记录时沿用原点评逻辑。

### 披露位置与示例（已实施）

本轮已按确认模板实施：先增加精简 section、标题顺序、编号顺延及预览一致性的失败测试，再调整报告构建并验证通过。仅调整月末总结，独立“未交作业统计”的模板和取数口径不变。

1. 有记录时保留原报告标题，将披露内容紧接标题下方，作为“一、课后复习提交情况”。零课堂、零复习但有未交记录时也采用此结构。
2. 正文只保留本月登记次数和全部对应正课日期；日期沿用完整 YYYY-MM-DD，按日期升序列出，不逐行重复说明。
3. 不再重复输出“学员：……；月份：……”，不保留“以上根据当前保留的登记记录汇总”尾注；汇总行使用“登记”说明数据来源。
4. 原“一、本月核心学习数据”至“四、教练暖心寄语”顺延为二至五，仅改编号，标题其余文字、装饰符号及正文不变。
5. 无记录时不插入新 section，原标题、一至四编号及内容不变，不推断所有作业均已完成。
6. 预览、TXT、剪贴板和提示使用一致的顺序：原标题 → 课后复习提交情况 → 原报告其余 section。

```text
开迪学员10🈷️月末总结

一、课后复习提交情况
本月登记未交作业 2 次，正课日期：
1. 2026-10-01
2. 2026-10-02

二、本月核心学习数据📊
（原内容不变）

三、本月表现点评🌟
（原内容不变）

四、下月小目标🎯
（原内容不变）

五、教练暖心寄语💌
（原内容不变）
```

报告只披露总次数及对应正课日期，不增加摘要、备注或状态。日期不得因 UTC 截断而偏移一天。

## 验收标准

| 场景 | 预期 |
| --- | --- |
| BFD 杨开迪点击课后复习方式 | 输出精简提醒并包含抄写、双向各一次默写、朗读、复习与提交要求；不自动新增记录 |
| 其他平台或其他学生点击课后复习方式 | 原通用文案不变 |
| 任意平台学生登记 | 只输入正课日期，保存、刷新后仍可查看 |
| 同日重复登记、取消、写入失败 | 同日仅一条；取消不保存；失败不虚报成功 |
| 同名学生跨平台、其他学生 | 列表、独立统计和月末报告均不串数据 |
| 跨月补录 | 10 月登记 9 月正课，归属 9 月统计和总结 |
| 新统计按钮位置 | 位于数据统计区，紧接抗遗忘统计 |
| 按天、按月统计 | 复用现有范围控件，包含范围边界，显示次数和对应正课日期 |
| 独立统计与月末总结 | 相同平台、学生、月份的总次数和明细一致 |
| 当月有记录 | 标题下面第一节披露登记次数及全部正课日期，不重复学员、月份和尾注；原 section 顺延为二至五；预览、复制、TXT、提示一致 |
| 面向家长的输出 | 分享正文、复制内容、TXT 内容及文件名均不出现平台名称、平台 ID 或多平台提示；未交说明只写一次，明细仅列正课日期 |
| 删除记录 | 列表移除；重新生成统计和月末总结时次数和日期同步减少 |
| 无记录、零课堂数据 | 无记录时原报告及一至四编号不变；零课堂但有记录时仍在标题下作为第一节披露 |
| 自动表扬 | 当月有未交记录时仅去掉“课后能主动打卡”；无记录时原点评不变 |
| 特殊字符、损坏数据 | 不执行 HTML；读取异常明确提示，不当作“没有记录” |
